# PolyPlayer — функциональность, история и текущее состояние

Состояние на 10 ноября 2026, версия **1.0.1**. Как устроен код — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Что это

PolyPlayer — бесплатный многопоточный аудиоплеер для мероприятий на Windows. Сделан для церкви «Слово веры» (Познань), где на служении нужно включать фоновую музыку перед началом, в перерывах и после окончания. Сейчас это нейтральный продукт с открытым кодом (GPL-3.0), без упоминаний церкви в программе и справке.

Автор и владелец — Виталий. Разработку вёл Claude (код, тексты, сайт, выпуски на GitHub); решения по продукту и текстам принимает Виталий.

## Функциональность (как сделано сейчас)

### Потоки
- Поток = папка с музыкой + название + цвет + громкость + настройки. Количество не ограничено.
- Создание: пустая карточка «Новый поток» → название (сразу видно, как оно ляжет на кнопку пульта) → «Выбрать…» папку → «Сохранить». Поток без аудиофайлов сохранить нельзя.
- Настройки потока: плавный старт и затухание (0–30 с, по умолчанию 3), переход треков (0–12 с, по умолчанию 5), перемешивать треки, начинать со случайного места (для длинных записей), по кругу, цвет, горячая клавиша.
- Карточка потока: ▶ пуск/пауза, ⏭ следующий трек, ■ стоп, полоса перемотки, ползунок громкости (запоминается), карандаш — изменить или удалить, стрелки ‹ › — порядок карточек. Внизу карточки — папка и метки: горячая клавиша, «перемешать», «с любого места», «один проход» (если «По кругу» выключено).
- Одновременно играет **один** поток: при включении другого тот, что играл, плавно затихает. (Настройка «Играет только один поток» была, убрана в 3.0.7 — смешивать потоки нельзя.)
- «Стоп всё» вверху окна — плавно выключает всю музыку; активна, только когда что-то играет.
- Если папку удалили, переименовали или отключили флешку — на карточке «Папка не найдена»; пустая папка — «В папке нет треков»; файлы не читаются — «Файлы не читаются», поток останавливается.

### Расписание
- Правило: поток, дни недели, время «с» и «до». В начале промежутка поток включается сам, к концу — плавно затихает.
- Без «с» правило только выключает; правило «Все потоки» в указанное время выключает любую музыку.
- Правило может переходить через полночь («с 23:50 до 00:10» — выключится уже на следующий день).
- Если компьютер включили позже времени «с», поток сам не запустится (решено сознательно: «догонять» пропущенные запуски не нужно).
- Вверху вкладки — «Следующее: …». Пустое расписание объясняет, как добавить правило.

### Горячие клавиши
- Каждому потоку — своё сочетание (пуск/пауза). В «Настройках» — сочетания для «Стоп всё» и «Следующего трека».
- Работают во всей системе, даже когда окно свёрнуто в трей. По умолчанию не назначены.
- Сочетание: минимум два модификатора, среди них Ctrl или Alt (например Ctrl+Alt+1), или F13–F24 без модификаторов. Esc — отмена, Backspace/Delete — убрать. Дубликаты запрещены. Если сочетание занято другой программой — подсвечивается красным.

### Пульт Stream Deck
- Плагин идёт в установщике. Если Stream Deck установлен, программа сама предлагает поставить плагин (один раз на версию); вручную — «Настройки» → «Установить плагин».
- Действия: «Поток», «Стоп всё», «След. трек», «PolyPlayer».
- «Поток» — новая кнопка сама предлагает поток: нажать — следующий, держать 1 с — выбрать. Потом: нажать — пуск/пауза, держать 1 с — стоп, держать 3 с — выбрать другой поток. Пока держите, кнопка показывает, что будет, если отпустить. Кнопка показывает название (заглавными, до 2 строк, одним размером), цвет, шкалу громкости; играет — светится.
- «Стоп всё» подсвечена, когда что-то играет. «След. трек» — следующий трек в играющем потоке. «PolyPlayer» показывает и прячет окно; серая — программа закрыта, нажатие её запустит.
- Stream Deck +: поток на регуляторе — поворот громкость, нажатие пуск/пауза, касание экрана следующий трек.
- Если программа закрыта, нажатие любой кнопки запускает её (в трей) и выполняет действие.

### Программа в целом
- Работает в трее: крестик прячет окно, музыка играет дальше. Меню трея: открыть/спрятать окно, «Стоп всё», «Выйти».
- «Запускать вместе с Windows» (запуск свёрнутым в трей). Один экземпляр: повторный запуск показывает окно.
- Обновления: при запуске проверяет GitHub, предлагает «Скачать и обновить», качает с прогрессом (окно можно скрыть, прогресс виден в «Настройках»), затем «Перезапустить» — тихая установка и автоматический перезапуск. Потоки и расписание сохраняются. В «Настройках» — версия, дата последней проверки, «Проверить обновления», «Что нового».
- Справка внутри программы (кнопка «?»): 5 разделов со скриншотами + «Если что-то не так». Шрифт Unbounded, название PolyPlayer — акцентом (Playfair Display bold italic, коралловый градиент).
- Установщик: для текущего пользователя, без прав администратора, в `%LOCALAPPDATA%\Programs\PolyPlayer`; ярлыки на рабочем столе и в «Пуске»; удаляет старую программу SWP Player (её настройки PolyPlayer переносит сам).
- Без интернета (нужен только для проверки обновлений), без учётных записей, рекламы и подписок.

### Сайт

## История разработки

- **SWP Player** (до ноября 2026) — первая версия для церкви: Node-сервер + окно в браузере (Edge), плагин Stream Deck. Затем перенос на Electron.
- **5–6 ноября 2026, версии 3.0.0–3.0.7** (рабочая нумерация, релизы потом удалены):
  - переименование в PolyPlayer, лого (волны, графит + коралл), GitHub-организация `polyplayer-app`, GPL-3.0, CI-выпуски, сайт на Pages;
  - обновления с согласия пользователя (скачать → перезапустить), исправление скрытых кнопок в окне обновления;
  - удалена функция «если компьютер включили позже — запустить поток»;
  - название на кнопке пульта: единый размер, до 2 строк, поля, запрет слишком длинных названий;
  - выбор потока на новой кнопке пульта (вариант Б: нажать — следующий, держать — выбрать);
  - горячие клавиши (3.0.4);
  - расписание через полночь, «Папка не найдена», чистые карточки, переписанные тексты (3.0.6);
  - один поток всегда, справка на Unbounded, короткие подсказки (3.0.7);
  - много итераций текстов сайта и справки, в том числе по аудитам Gemini (с правкой штампов и неверных обещаний).
- **6 ноября 2026 — сброс на 1.0.0.** Все релизы 3.0.x и теги удалены (история коммитов сохранена), выпущена 1.0.0 с обзорным описанием.
- **10 ноября 2026 — 1.0.1.** Исправлены кракозябры в окнах установщика (issue #1): `installer.nsi` в UTF-8 с BOM + `/INPUTCHARSET UTF8`; обновлены тексты приветствия и финальной страницы установщика. Проверено по самому выпущенному exe: в 1.0.0 строки были испорчены, в 1.0.1 — нет. Тесты перенесены в репозиторий (`tests/`).

## Текущее состояние

- Выпущена **1.0.1**, все автотесты проходят (`tests/run.sh`).
- Ставится на церковный компьютер (7 ноября установка 1.0.0 показала issue #1 — исправлено в 1.0.1, на Windows вживую ещё не проверено).
- Проверено только автотестами (Linux, Chromium/Electron): горячие клавиши через `globalShortcut`, работа с настоящим Stream Deck и установщик с окнами на Windows вживую не проверялись.

## Известные проблемы и ограничения

- **После сброса версий плагин 3.0.x не обновится сам.** Программа предлагает плагин, только если установленный старее программы, а 3.0.7.0 «новее» 1.0.1. Где стоял плагин 3.0.x, его нужно один раз переустановить: «Настройки» → «Установить плагин» (если Stream Deck откажется ставить «старую» версию — сначала удалить плагин в Stream Deck). Возможная правка: предлагать плагин при любом несовпадении версий, а не только когда он старее.
- Компьютеры с 3.0.x не увидят 1.0.x как обновление — нужна ручная установка поверх (настройки сохраняются).
- Нет подписи кода — Windows показывает SmartScreen («Подробнее» → «Выполнить в любом случае»).
- Только Windows (плагин умеет macOS, но программа под Mac не собирается).
- Фото Stream Deck Mini на сайте — фотография Elgato, в которую вписаны наши кнопки. Лучше заменить своей фотографией.

## Идеи и планы (не начато)

- Своя фотография пульта для сайта.
- Английская версия сайта.
- Unbounded в основном окне программы (сейчас Inter; в справке уже Unbounded) — предлагалось, решения нет.
- Предлагать плагин при любом несовпадении версий (см. выше).
- Проверка на Windows: горячие клавиши в фоне, занятые сочетания, установка с окнами, Stream Deck + регулятор.

## Как продолжать работу

- **Тексты** (программа, справка, сайт, README, описания выпусков) — на естественном русском, без кальки, канцелярита и штампов; каждое утверждение — правда; без лишних деталей. Термины одинаковые везде: «поток» (на сайте допустим синоним «плейлист»), «трей», «Стоп всё», «Следующий трек». Неразрывные пробелы — после коротких предлогов/союзов и перед тире. Для правок текстов есть скилл `ru-product-texts`.
- **Перед изменением поведения** — обсудить с Виталием; аудиты сторонних нейросетей разбирать критически (проверять факты по коду), приходить к одному варианту.
- **Выпуск**: поднять версию и `releaseDate` в `package.json`, написать `RELEASE_NOTES.md` (раздел «Что нового в X.Y.Z» + обзор), прогнать `tests/run.sh`, запушить в `main`, дождаться workflow `Release`, проверить файлы выпуска.
- **Ограничения сессий Claude Code** (облачная среда): пуш в `main` работает; создание тегов, удаление веток и релизов через API, GraphQL (`gh issue create`, `gh release download`) — запрещены. Обходы: релизы создаёт CI; issue — `gh api repos/polyplayer-app/polyplayer/issues -f title=… -F body=@file`; скачать файл выпуска — `gh api -H "Accept: application/octet-stream" repos/…/releases/assets/<id>`; удалить релизы/ветки — разовым workflow (как `cleanup.yml` в истории). github.io из сессии недоступен — состояние Pages проверять через Actions API.
- **Если код вставляет Виталий вручную** — присылать файл целиком, не фрагменты.
