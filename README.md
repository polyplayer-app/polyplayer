# PolyPlayer

Бесплатная программа для Windows: фоновая музыка одним нажатием или по расписанию. Выберите папки с музыкой, создайте из них потоки и управляйте ими так, как удобно: кнопками в окне программы, горячими клавишами, с пульта Stream Deck или по расписанию. Работает без интернета, подписок и рекламы.

- сколько угодно потоков: у каждого своя папка с музыкой, громкость и цвет;
- плавное нарастание и затухание, треки перетекают друг в друга;
- расписание по дням недели и времени, правило «Все потоки» выключает любую музыку в нужный момент;
- горячие клавиши для каждого потока;
- управление с пульта Elgato Stream Deck: каждый поток на своей кнопке (плагин ставится вместе с программой);
- запускается вместе с Windows и работает в фоне, даже когда окно закрыто;
- сам сообщает о новых версиях и обновляется за пару минут.

## Установка

**[Скачать PolyPlayer для Windows](https://github.com/polyplayer-app/polyplayer/releases/latest/download/PolyPlayer-Setup.exe)** — ссылка всегда ведёт на последнюю версию.

1. Запустите скачанный файл. Если Windows покажет «Windows защитил ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
2. Если на компьютере есть Stream Deck, после первого запуска PolyPlayer предложит установить плагин для пульта (он внутри установщика).
3. Дальше программа обновляется сама.

Страница для скачивания: https://polyplayer-app.github.io/polyplayer/

Потоки и расписание хранятся в `%APPDATA%\PolyPlayer`.

## Как устроено

- `main.js` — программа (Electron): окно, значок в трее, автозапуск, обновления.
- `app/server.js` — потоки, расписание, связь с окном и пультом (без внешних зависимостей).
- `app/public/index.html` — окно программы и проигрыватель (Web Audio).
- `plugin/com.polyplayer.deck.sdPlugin` — плагин Stream Deck, подключается к программе как пульт.
- `installer.nsi` — установщик (NSIS).

Выпуск собирается автоматически (GitHub Actions, `.github/workflows/release.yml`): когда в `main` попадает новая версия в `package.json`, GitHub собирает установщик и плагин и публикует выпуск `vX.Y.Z`.
