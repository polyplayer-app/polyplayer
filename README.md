# PolyPlayer

Фоновая музыка в несколько потоков для Windows: перед началом мероприятия, в перерыве, под объявления, в конце.

- несколько потоков (папок с музыкой), плавное нарастание и затухание, переходы между треками;
- расписание: включить и выключить поток в заданное время, «стоп всё» к началу;
- управление с пульта Elgato Stream Deck (плагин в каждом релизе);
- работает в значке возле часов, сам запускается вместе с Windows;
- сам проверяет обновления и ставит их по кнопке, когда музыка не играет.

## Установка

1. Скачайте из раздела [Releases](../../releases/latest) файл `PolyPlayer-Setup-….exe` и запустите его.
   Windows может показать «Windows защитил ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
2. Для Stream Deck скачайте там же `PolyPlayer.streamDeckPlugin` и откройте его двойным кликом.

Потоки и расписание хранятся в `%APPDATA%\PolyPlayer`.
