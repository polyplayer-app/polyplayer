# PolyPlayer

Бесплатный многопоточный аудиоплеер для мероприятий на Windows. У каждого потока своя папка с музыкой, громкость и настройки; включать потоки можно кнопками в окне программы, горячими клавишами, с пульта Stream Deck или по расписанию. Работает без интернета, подписок и рекламы.

- сколько угодно потоков; одновременно звучит один, при переключении музыка сменяется плавно;
- плавное нарастание и затухание, треки перетекают друг в друга;
- расписание по дням недели и времени, в том числе через полночь; правило «Все потоки» выключает любую музыку в нужный момент;
- горячие клавиши для каждого потока, «Стоп всё» и «Следующего трека» — работают, даже когда окно свёрнуто;
- управление с пульта Elgato Stream Deck: каждый поток на своей кнопке (плагин ставится вместе с программой);
- запускается вместе с Windows и работает в трее;
- сам проверяет новые версии и обновляется с вашего согласия.

## Установка

**[Скачать PolyPlayer для Windows](https://github.com/polyplayer-app/polyplayer/releases/latest/download/PolyPlayer-Setup.exe)** — ссылка всегда ведёт на последнюю версию.

1. Запустите скачанный файл. Если Windows покажет синее окно SmartScreen, нажмите «Подробнее», затем «Выполнить в любом случае».
2. Если на компьютере есть Stream Deck, после первого запуска PolyPlayer предложит установить плагин для пульта (он внутри установщика).
3. Дальше программа обновляется сама.

Страница для скачивания: https://polyplayer-app.github.io/polyplayer/

Потоки и расписание хранятся в `%APPDATA%\PolyPlayer`.

## Для разработчиков

- [ARCHITECTURE.md](ARCHITECTURE.md) — стек, устройство кода, сборка и выпуск, тесты.
- [STATUS.md](STATUS.md) — функциональность, история разработки, текущее состояние и планы.

Выпуск собирается автоматически (GitHub Actions): когда в `main` попадает новая версия в `package.json`, GitHub собирает установщик и плагин и публикует выпуск `vX.Y.Z`. Автотесты — `tests/run.sh`.
