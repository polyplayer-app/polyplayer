# PolyPlayer — заметки для Claude

Перед работой прочитай:
- [ARCHITECTURE.md](ARCHITECTURE.md) — стек, устройство кода, сборка, выпуск, тесты;
- [STATUS.md](STATUS.md) — что программа умеет, история, текущее состояние, известные проблемы, правила работы.

Коротко:
- Язык общения и всех текстов — русский. Тексты для пользователей: естественный язык, без штампов и кальки, только правда (скилл `ru-product-texts`, если доступен).
- Выпуск = новая `version` в `package.json` + `RELEASE_NOTES.md` + пуш в `main` (CI собирает и публикует). Сначала `tests/run.sh`.
- `installer.nsi` хранить в UTF-8 с BOM.
- Поведение программы и тексты меняем только после согласования с владельцем (Виталий).
- Обновляй STATUS.md, когда что-то меняется в функциональности или состоянии.
